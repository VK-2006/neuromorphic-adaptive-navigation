# Navora merged update — 2026-08-12

This archive consolidates the fixes validated during the Windows local run.

## Included fixes

- Express 5 compatible backend route registration.
- `GET /api/v1/auth/config` route and controller support.
- Complete authentication validators for register, login, OTP, email-only requests, reset-password, and Google ID-token flows.
- Development-only OTP fallback when Brevo delivery is unavailable; production never returns the plaintext OTP.
- OTP verification returns the consumed record so the password-reset flow can attach a short-lived reset token.
- Brevo provider timeout/degraded-mode handling.
- Brevo endpoint is constructed as a URL constant to avoid chat/markdown link corruption when code is copied.
- Dependency targets updated to the locally validated major/minor lines:
  - Express `^5.2.1`
  - Google Auth Library `^11.0.1`
  - Mongoose `^8.24.3`
