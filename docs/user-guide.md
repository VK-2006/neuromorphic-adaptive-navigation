# User Guide

Navigate: enter latitude/longitude or use current location, compare routes and review `WHY THIS ROUTE?`. Live Journey: explicitly start camera if wanted, toggle detection, start/pause tracking, enable voice and use SOS only when intended. World Chat: do not reveal precise location publicly. Devices: Bluetooth is for control/metadata; video uses supported camera/WebRTC/network streams. Settings support LIGHT/DARK/SYSTEM and reduced motion.
