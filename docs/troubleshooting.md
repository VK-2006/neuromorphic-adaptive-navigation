# Troubleshooting

MongoDB unavailable: backend starts degraded, but DB-backed auth/journey writes require MongoDB. AI unavailable: backend camera endpoint returns degraded metadata instead of crashing. OSRM unavailable: choose simulation mode; mock geometry is visibly labelled. Camera/GPS denied: grant browser permission or use simulation. Brevo/Google unavailable: credentials are required; this is not a coding failure. WebAuthn on localhost works in compatible browsers; production requires HTTPS and correct RP ID/origin.
